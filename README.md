PORTOFOLIO LULU SOLIKHA
======================

Isi folder:
- index.html  : isi halaman portofolio
- style.css   : tampilan dan responsivitas
- script.js   : menu navigasi dan preview sertifikat
- assets/     : tempat menyimpan foto profil, gambar project, dan sertifikat

CARA MEMBUKA DI VS CODE
1. Ekstrak file ZIP ini.
2. Buka VS Code.
3. Pilih File > Open Folder.
4. Pilih folder portofolio-lulu-final.
5. Buka index.html dengan ekstensi Live Server atau buka langsung di browser.

TOOLS YANG SUDAH DIMASUKKAN DENGAN LOGO
Canva, Figma, CapCut, Adobe Photoshop, Microsoft Word, Microsoft Excel,
PowerPoint, VS Code, PHP, HTML, dan CSS.

Logo tools dimuat dari Simple Icons melalui internet, jadi koneksi internet
diperlukan agar logo eksternal dapat tampil.

CARA MENAMBAHKAN SERTIFIKAT NANTI
1. Salin gambar sertifikat ke folder assets. Contoh: assets/sertifikat-1.jpg
2. Di index.html, cari kartu sertifikat yang ingin diisi.
3. Ubah data-title menjadi nama sertifikat.
4. Ubah data-image menjadi lokasi file, contoh: data-image="assets/sertifikat-1.jpg"
5. Ubah tulisan Tambahkan Sertifikat 1 menjadi nama sertifikat.
6. Ubah Penyelenggara · Tahun sesuai sertifikat.
7. Simpan dengan Ctrl + S.
